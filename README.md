## Project Overview

A complete multivariate statistical analysis of the WHO Life Expectancy dataset covering **193 countries** across 16 years (2000–2015). After removing missing values the working dataset contains **1 649 observations** and **19 numeric variables** spanning health, economic, and social indicators.
## Quick Start

### 1. Install dependencies

```bash
pip install numpy pandas matplotlib seaborn scipy scikit-learn statsmodels
```

### 2. Run the notebook

Open `project.ipynb` in Jupyter, VS Code, or Cursor and run all cells top-to-bottom.  
All plots will display inline **and** be saved to `figures/`.
